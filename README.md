# AquaGeoAI Website

Static responsive website inspired by the information architecture of the supplied NIEES reference site.

## Pages
Home, About Us, Focal Areas, Gallery, News, Publications, Contact Us, Lineup.

## Run locally
Open `index.html` in a browser, or serve the folder:
`python -m http.server 8000`

## Customise
Replace the placeholder address, phone and email in `contact.html` and `index.html/footer`.
Add real images to the Gallery section and connect the contact form to an email/API service.
